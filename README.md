# Номера города

Мобильная HTML-игра в одном файле: выбивай редкие автономера (Россия, Беларусь, ОАЭ, США, Франция, Испания), собирай коллекцию, покупай машины и катайся по 3D-городам.

- 5 городов, гоночная трасса и каскадёрский полигон
- 18 машин, тюнинг, нитро, дрифт, винилы
- светофоры, машины NPC, спецтранспорт, смена дня и ночи
- повреждения, кувырки на трамплинах, музыка в поездке

Играть: https://arturok3838-bot.github.io/nomera-goroda/

Прогресс сохраняется в браузере; в настройках можно скопировать код или скачать файл сохранения и перенести прогресс на другое устройство.

Запуск локально: открыть `index.html` в браузере. 3D — three.js r149 (MIT), встроен в файл.
